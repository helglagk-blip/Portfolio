Проект: Анализ данных для агентства недвижимости

Целью проекта является выявление закономерностей в сезонности подачи объявлений и времени активности объявлений.

Задачи: анализ ключевых метрик, разработка дашборда, решение ad hoc задач заказчика, включающих сегментный анализ рынка недвижимости.

Стек: SQL, PostgreSQL, DataLens
