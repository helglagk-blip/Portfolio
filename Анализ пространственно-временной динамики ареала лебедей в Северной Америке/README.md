Проект: Анализ пространственно-временной динамики ареала лебедей в Северной Америке

Цель проекта: определить, наблюдается ли статистически значимое смещение ареала лебедей в Северной Америке, и выявить, различается ли это смещение в разных географических зонах. Оценить влияние внешних факторов (температура, плотность населения) на пространственное распределение птиц.

Задачи: предобработка данных, кластерный анализ для выделения географических зон, выявление сезонности и других искажающих факторов, статистический анализ смещения ареала обитания лебедей.

Стек: Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, phik_matrix, EDA
