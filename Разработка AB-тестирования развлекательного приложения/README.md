Проект: Разработка A/B-тестирования развлекательного приложения с функцией «бесконечной» ленты

Целью проекта является проверка нового алгоритма рекомендаций, который, по мнению команды разработчиков рекомендательных систем, будет показывать более интересный контент для каждого пользователя.

Задачи: рассчитать параметры A/B-теста, который позволит проверить гипотезу об улучшении рекомендаций, и проанализировать его результаты.

Стек: Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, scipy.stats
